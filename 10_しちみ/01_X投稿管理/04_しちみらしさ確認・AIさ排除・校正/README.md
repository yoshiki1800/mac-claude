# STEP 4｜しちみらしさ確認・AIさ排除・校正

## 目的
AI感を消し、しちみの言葉として自然に読める文章に整える。

---

## AI臭チェックリスト（当てはまったら修正）

### ❌ AI臭が出やすいワード・表現
- 「〜することが重要です」→ 説教くさい
- 「〜を意識しましょう」→ 上から目線
- 「まず〜です。次に〜です。最後に〜です。」→ 箇条書きすぎ
- 「〜というわけです」→ まとめっぽすぎ
- 「非常に」「大変」「とても」の多用
- 「〜においては」「〜に関しては」→ 硬い
- 同じ語尾が続く（「〜です。〜です。〜です。」）

### ✅ しちみらしい表現に直す
| AI臭あり | しちみらしく |
|---------|------------|
| 「重要です」 | 「大事だと思う」「これ結構でかい」 |
| 「意識しましょう」 | 「気にしてみてください」「やってみてほしい」 |
| 「非常に効果的」 | 「マジで効いた」「これ結構効く笑」 |
| 「〜を実践することで」 | 「〜やってみたら」 |

---

## しちみらしさチェックリスト

- [ ] ブラック職場・日本語教師のキャラが自然に出ているか
- [ ] 「笑」が不自然な場所にないか（入れすぎ・入れなさすぎ）
- [ ] 上から目線になっていないか（あくまで「自分の話」スタンスか）
- [ ] 最初の1行で止まれるか（スクロールを止められる書き出しか）
- [ ] 人間が書いた感があるか（体験・感情が入っているか）
- [ ] 改行は適切か（詰まりすぎていないか）

---

## 校正チェック

- [ ] 誤字・脱字がないか
- [ ] 140字を超えていないか（投稿前に必ず確認）
- [ ] ハッシュタグは適切か（多すぎない・関係あるか）
- [ ] URLやnoteリンクを入れる場合、意図通りの配置か
