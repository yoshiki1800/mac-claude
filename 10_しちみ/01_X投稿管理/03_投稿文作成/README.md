# STEP 3｜投稿文作成

## 目的
しちみのキャラクターで投稿文の下書きを作る。

---

## しちみの文章スタイル

### 基本ルール
- **文体**：ですます調ベース。ときどきだ調を混ぜる
- **改行**：こまめに入れて読みやすく（Xは詰まると読まれない）
- **長さ**：130〜140字を狙う（全部読める×情報が入る）
- **絵文字**：1〜2個。使いすぎない
- **「笑」**：自然に使う。「笑笑」もOK

### しちみらしいフレーズ・口癖
- 「またAI触ってた」「深夜に」
- 「ブラック職場なのに」「日本語教師なのに」
- 「正直に言うと」「リアルな話をすると」
- 「月5万達成して気づいたこと」
- 「怪しいノウハウじゃなくて」

---

## 投稿フォーマット（型）

### 型①：共感ファーストの型
```
【あるある・共感できる状況を1行で】

【自分のリアルな話につなげる】
【気づき・変化を話す】

【まとめ・メッセージ】
```

### 型②：学び・気づきの型
```
【気づきを一言でズバッと】

【なぜそう思ったか・きっかけ】
【具体的な内容・説明】

【読者へのメッセージ or 問いかけ】
```

### 型③：数字・実績の型
```
【数字をドンと出す】

【その数字の裏にあるリアル】
【失敗・苦労・気づき】

【これからどうするか・読者へ】
```

---

## 作成時の注意

- 最初の1行が命（流し読みされる中で止めてもらう）
- 「教えてあげる」トーンにならない。あくまで「自分の話」スタンス
- noteやLINEへの誘導は週に数回程度。毎回は入れない
