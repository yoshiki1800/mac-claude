# STEP 3｜投稿文作成

## 目的
しちみのキャラクターで投稿文の下書きを作る。

---

## しちみの文章スタイル

### 基本ルール
- **文体**：ですます調ベース。ときどきだ調を混ぜる
- **改行**：こまめに入れて読みやすく（Xは詰まると読まれない）
- **長さ**：130〜140字を狙う（全部読める×情報が入る）
- **絵文字**：1〜2個。使いすぎない
- **「笑」**：自然に使う。「笑笑」もOK

### しちみらしいフレーズ・口癖
- 「またAI触ってた」「深夜に」
- 「ブラック職場なのに」「日本語教師なのに」
- 「正直に言うと」「リアルな話をすると」
- 「月5万達成して気づいたこと」
- 「怪しいノウハウじゃなくて」

---

## 投稿フォーマット（型）

### 型①：共感ファーストの型
```
【あるある・共感できる状況を1行で】

【自分のリアルな話につなげる】
【気づき・変化を話す】

【まとめ・メッセージ】
```

### 型②：学び・気づきの型
```
【気づきを一言でズバッと】

【なぜそう思ったか・きっかけ】
【具体的な内容・説明】

【読者へのメッセージ or 問いかけ】
```

### 型③：数字・実績の型
```
【数字をドンと出す】

【その数字の裏にあるリアル】
【失敗・苦労・気づき】

【これからどうするか・読者へ】
```

---

## 作成時の注意

- 最初の1行が命（流し読みされる中で止めてもらう）
- 「教えてあげる」トーンにならない。あくまで「自分の話」スタンス
- noteやLINEへの誘導は週に数回程度。毎回は入れない

## 投稿ストック｜使える型メモ

### 月曜朝／宣言型（2026-06-15 発見）

**参考：たこまる (@taco...) の投稿構造（インプ755・いいね52）**

伸びた理由：「宣言だけ」じゃなく **「弱み＋達成＋宣言」のセット**になっている。

```
【月曜あるある共感フック（どんより感・疲労など）】

【直近の弱みをさらす（うまくいってないこと）】
【でも直近の達成を添える（具体的な事実）】

【今週の一番大きな宣言（1つに絞る）】

【応援したくなる締め（決意表明じゃなく素直な感情）】
```

**しちみ版イメージ：**
```
月曜＆ブラック職場＆睡眠不足のどんよりスタート笑

それでも先週ToDoアプリを完成させたから
今週は初AI動画の投稿まで持っていく

正直まだクオリティ低い
でもまず出すことが大事だと思ってる

重めの月曜だけど、動きます
```

**使いどころ：** 月曜朝 or 週の始まり。直近に「完成・達成」したことがある週に使う。
