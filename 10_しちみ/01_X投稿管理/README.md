# 01_X投稿管理｜投稿作成フロー

## 概要
投稿を作成するたびに、以下の5ステップを必ず順番に実行する。

---

## 投稿作成フロー（毎回必須）

```
STEP 1：アカウント確認・分析
  └ 最近の投稿のインプ・いいね・トレンドを確認

STEP 2：テーマ・キーワード選定
  └ 今日投稿するテーマと使うキーワードを決める

STEP 3：投稿文作成
  └ しちみのキャラクターで下書きを書く

STEP 4：しちみらしさ確認・AIさ排除・校正
  └ AI臭を消す・しちみの言葉に整える

STEP 5：インプレッションチェック
  └ 伸びそうか最終確認してからポスト
```
