# STEP 2｜テーマ・キーワード選定

## 目的
今日の投稿で扱うテーマと、検索・拡散に使うキーワードを決める。

---

## しちみアカウントの投稿テーマ軸

### 軸①：日常×AI副業のリアル（共感系）
- ブラック職場での愚痴・日常エピソード
- 「深夜にまたAI触ってる」系の日常
- 副業あるある・サラリーマンあるある

### 軸②：学び・気づきのシェア（価値提供系）
- AIツールの使い方・活用法
- note攻略・SNS攻略のリアルな気づき
- 副業で稼ぐための思考・マインド

### 軸③：実績・数字の公開（信頼構築系）
- note売上の公開
- フォロワー増加の記録
- 失敗談も含めたリアルな進捗報告

### 軸④：ファン育成（キャラ立て系）
- しちみ自身の人柄が出るネタ
- 「また深夜に…」「日本語教師なのに…」などのギャップネタ

## テーマ選定の基準

1. STEP 1で「伸びたネタ」と近いテーマか？
2. しちみのキャラクターに合っているか？
3. 読んだ人が「いいね」か「保存」したくなるか？
4. noteやLINEへの誘導につながるか？
