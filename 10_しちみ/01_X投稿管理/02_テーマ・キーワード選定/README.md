# STEP 2｜テーマ・キーワード選定

## 目的
今日の投稿で扱うテーマと、検索・拡散に使うキーワードを決める。
2026-06-24時点の実績データ（03の投稿ストック・05の数字記録）を踏まえ、軸を優先度別に並べてある。**上から順に検討し、最優先軸で書けるネタがあればそれを使う。**

---

## テーマ軸（優先度順）

### 🥇 最優先（実績で結果が出ている）

**A. 技術・実務軸**
- 使ったプロンプト・ツール名・ワークフローを具体的に見せる「気づき」
- 「気づきを一言」で終わらせず、何を・どうやったかまで書く（ツール名、プロンプトの一部、手順）
- 例：「AIって業務改善だけに使うのもったいない」（インプ49・自己発信では最好調）

**B. 引用RT**
- 大型AI系アカウントへの引用RT。リーチの大きい投稿ほど効果が出る
- 実績：あいく@AIで2億への引用RT → インプ132・フォロワー272→274

### 🥈 次に試す（ざえもん分析より。しちみ未着手だが理論的に強い）

**C. 不安の実況中継**
- 結果が出る前の「これ大丈夫かな」をそのまま流す。成功してからの後出し報告にしない

**D. 逆境のポジティブ転換**
- ブラック労働・失敗・トラブルを、マイナスのまま終わらせず転換の一言を必ず添える

**E. 人間的な目標への紐付け**
- 「将来、自分の日本語学校を作りたい」という夢を稼ぐ理由として前面に出す

**F. マイルストーンを祝う**
- フォロワー・売上の節目（次は300人など）は必ず投稿化する

### 🥉 条件付き（単体では使わない）

**G. つぶやき系・宣言系・職場ネタ単体**
- 検証済みで繰り返し低調（2026-06-15、06-22、06-23）
- 使う場合は必ずA（技術・実務の気づき）かD（逆境転換）とセットにする。気づき・転換のない単純な愚痴・宣言・振り返りは選ばない

## テーマ選定の基準

1. 最優先軸（A・B）で書けるネタがあるか？
2. なければ次点軸（C〜F）で書けるか？
3. G（つぶやき・宣言・職場ネタ）しかない日は、AかDと組み合わせられるか確認する。組み合わせられないなら別日に回す
4. しちみのキャラクターに合っているか？
5. noteやLINEへの誘導につながるか？
