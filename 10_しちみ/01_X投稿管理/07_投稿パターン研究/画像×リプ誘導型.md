## パターンの構造

### 本ポスト（メイン）
```
【強いフック＋ハードルを潰す一言】

【数字で価値を予告】
「12のプロンプトがある⬇️」

【画像：テーマを視覚化したシンプルなもの】
```

### リプライツリー（本編）
```
1. 〇〇
Prompt:「〜〜〜」

2. 〇〇
Prompt:「〜〜〜」

（N個まで連続投稿）
```

---

## なぜ伸びるか

| 理由 | 説明 |
|------|------|
| 数字の予告 | 「12個ある」で最後まで読む動機ができる |
| ⬇️リプ誘導 | リプライも全部インプにカウントされる |
| 画像 | タイムラインで目が止まる |
| 保存・RT誘発 | 有用情報まとめは「後で使う」で保存される |
| ハードル排除フック | 「カメラなし・編集なし・顔出しなし」→「自分でもできる」と思わせる |

## しちみ版への応用アイデア

### テーマ例
- 「ブラック職場でも副業できるN個の習慣」
- 「AI副業で使ってるN個のプロンプト」
- 「note月5万を達成したときにやったN個のこと」
- 「Antigravityで使えるN個のプロンプト」

### フック例
```
コードなし。カメラなし。深夜2時間だけ。

ブラック職場の会社員がAI副業で月5万稼いだ
7つの習慣⬇️
```

### 注意点
- 画像は**シンプルで文字大きめ**が正解（凝ったデザイン不要）
- リプに書く内容は**実際に使えるもの**に限定（薄いと保存されない）
- 「N選」の数字は5〜12が適切

フォロワーが増えてきた段階（300人〜）で試す価値あり。
保存・RTが稼げるので一気にリーチが広がる。
