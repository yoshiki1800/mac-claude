# STEP 5｜インプレッションチェック

## 目的
投稿前に「これは伸びるか？」を最終確認する。

---

## 🚦 価値ゲート（最初に必ず通す）

このゲートをクリアできない投稿は、下のチェックリストに進まず作り直す。

- [ ] **技術・実務の具体性があるか**：ツール名・プロンプト・手順など、読者が持って帰れる具体が入っているか（一言の感想で終わっていないか）
- [ ] **読者にとっての価値があるか**：「この投稿で読者は何を得られるか」に答えがあるか。答えがなければ作り直す
- [ ] **後出しになっていないか**：成功・解決してから語るのではなく、結果が分かる前の不安や進行中の状態を出せているか（出せる場面なら優先する）

⚠️ 過去の検証で、下のチェックリストに全部◯がついても、この価値ゲートを満たさない投稿（職場ネタ単体・つぶやき系）は繰り返し低調だった（2026-06-16、06-23）。**チェックリストより先にこのゲートを優先する。**

---

## インプレッションが伸びる投稿の条件

### ① 最初の1行で止められるか
- 読んでいて「え、なに？」と思わせられるか
- 数字・疑問・共感・意外性のどれかが入っているか

**例：止まる1行**
```
「副業って結局センスじゃない？」って言われた
月5万稼ぐまでにやめようとした回数、数えたら7回だった
深夜2時にまたAI触ってた笑
```

**例：止まらない1行**
```
今日はAIについて話します
副業について考えました
```

---

### ② リプ・いいね・保存のどれかを誘発するか

| 反応 | 誘発する投稿の特徴 |
|------|----------------|
| いいね | 共感できる・刺さる一言 |
| リプ | 問いかけ・続きが気になる・賛否が分かれる |
| 保存 | 具体的なノウハウ・後で見返したい情報 |
| リポスト | 「これ広めたい」と思わせる・誰かに教えたい |

---

### ③ 最終チェック項目

- [ ] 最初の1行で「続きを読みたい」と思えるか
- [ ] 読み終わったあとに何かしたくなるか（いいね・リプ・保存）
- [ ] しちみのキャラクターが出ているか（STEP 4確認済みか）
- [ ] 投稿する時間帯は適切か（推奨：7時・12時・19時〜21時）
- [ ] 直近の投稿と内容が被っていないか

---

### ④ 投稿時間の目安

| 時間帯 | 特徴 |
|--------|------|
| 7:00〜8:00 | 朝の通勤・起き抜けに見る人が多い |
| 12:00〜13:00 | 昼休みのスマホ率が高い |
| 19:00〜21:00 | 退勤後・夜のゴールデンタイム |
| 22:00〜23:00 | 深夜派のコアファン向け（しちみキャラには合う） |

---

→ 結果を 05_数字管理 に記録する
